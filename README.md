# 📱 Mini-App 5: Lanterna Inteligente

## 🎯 Objetivo
Praticar o uso de **sensores do dispositivo** e **permissões** no Android.

## 📋 Funcionalidades
- Detectar a luminosidade ambiente com o **sensor de luz**.
- Se estiver escuro, ligar a lanterna automaticamente.
- Permitir ligar/desligar a lanterna também por **botão manual**.
- Exibir no app o **nível atual de luminosidade** detectado.

## ✅ Requisitos Técnicos
- Acesso ao **sensor de luminosidade**.
- Controle da **lanterna** via API do Android.
- Interface criada com **Jetpack Compose**.
- Gerenciamento de permissões em tempo de execução.
